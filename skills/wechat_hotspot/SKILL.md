# 目标
生成每日《漢洋海运·热点解码》公众号文章。

# 输入
- 当前日期
- data/article_history.json 的最近14天历史
- 网络检索结果

# 工作流程
1. 读取 data/article_history.json
2. 搜索最近24小时内的航运相关新闻；若不足，再扩展到48小时
3. 仅保留海外权威媒体来源
4. 生成候选主题清单，至少5条
5. 与最近14天历史比对，排除高度重复题材
6. 选择：
   - 1个主线事件
   - 0到2个辅助事件
7. 生成一篇1100-1300字中文文章
8. 输出格式必须包含：
   - 标题
   - 导语
   - 3-5个小标题分段
   - 结尾总结
   - 来源列表
9. 保存文章到 outputs/YYYY-MM-DD-热点解码.md
10. 更新 data/article_history.json

# 选题规则
- 优先“航运影响强”的新闻，而不是泛财经新闻
- 优先对运价、航线、货流、港口、燃油、保险、风险溢价有直接影响的事件
- 如果头条新闻过强，可以围绕单一事件深挖，不必硬拼多条新闻
- 不要为了凑热闹选和航运关系很弱的新闻

# 写作规则
- 不是简单新闻复述，必须是“新闻驱动的航运解读”
- 必须明确落脚到航运市场
- 必须给出后续观察点
- 不使用文内引用格式
- 不编造数字，不写不确定的具体数据
- 如无法确认精确数字，可用趋势性表述代替

# 标题优化规则
- 标题前半句给出核心冲突或变化
- 后半句落到航运
- 保持专业，不要夸张，不要低俗
- 避免和近14天标题高度相似

# 文末来源格式
来源：

Maritime Executive — xxxx
